# Project Instructions & Rules: Fantrax Assistant

## Branching & Commit Directives (CRITICAL)
- **NEVER work directly on `main` or commit directly to `main`**: Always create a dedicated feature or bugfix branch (e.g. `feat/...` or `fix/...`) for any work.
- **NEVER merge into `main` without explicit user approval**.
- **Always push branches to origin** when requested or completed.

## Data Priority Directives
- **Fantrax First**: Always use Fantrax data (`fantrax_info`) as the #1 primary source of truth for fantasy counting statistics (goals, assists, clean sheets, cards, points, FP/G).
